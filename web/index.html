Recommending for the whole session, not the next click

SlateQ vs myopic slate recommendation in RecSim Interest Evolution, a simulated video platform.

PILOT DATA. These numbers come from a short plumbing run and are not results.

The question

A recommender shows a slate of k videos chosen from N candidates. A myopic recommender shows whatever is most likely to be clicked now. But in the simulator, a user has a limited time budget: watching a high-quality video gives some time back, so the session lasts longer. SlateQ is a reinforcement-learning method that values each item by its long-term effect on the session, and it stays tractable because it decomposes the slate's value into per-item values.

  1. RQ1 Does SlateQ give more total watch time per session than a myopic recommender?
  2. RQ2 How does that gap change with catalog size N and slate size k?
  3. RQ3 How sensitive is SlateQ's advantage to a wrong assumption about how users choose?

How the evidence was produced

Policies

  • SlateQ learns per-item long-term values (γ = 0.99) and picks the top-k by click-probability × value.
  • Learned myopic is the same agent with γ = 0: same architecture, data, training budget and tuning budget. Each agent uses its own tuned learning rate, so the horizon is the main difference but not the only one. This is the primary comparison.
  • Oracle myopic reads the user's true interests and ranks by click probability: the best a click-maximiser can do. It has privileged information.
  • Random picks k candidates uniformly.

Protocol (fixed before the runs)

    Limitations

    • Simulated users, not real ones: results describe RecSim Interest Evolution only.
    • Candidates are redrawn every step, so "catalog size" means candidates per step.
    • SlateQ is a PyTorch re-implementation of RecSim's TF agent, tested against its scoring functions, not run side by side.
    • Following the reference implementation, the no-click option carries no continuation value, which shortens SlateQ's effective horizon.
    • Five run seeds: we report effect sizes and confidence intervals, not significance tests.
