# mladenov2021recsimng: Mladenov et al. 2021, RecSim NG (arXiv preprint)

- **Status:** arXiv:2103.08057, preprint.
- **Evidence level:** E2 (abstract and introduction).
- **Claim (own words):** a probabilistic-programming simulator for multi-agent recommender ecosystems, built on Edward2 and TensorFlow, as a successor platform to RecSim.
- **Use:** context. We use the original RecSim because SlateQ's reference agent and Interest Evolution live there, and RecSim NG requires TensorFlow (excluded by our stack, D1).
