# ie2019recsim: Ie et al. 2019, RecSim (arXiv preprint)

## Citation and status

- Ie, Hsu, Mladenov, Jain, Narvekar, Wang, Wu, Boutilier, "RecSim: A Configurable Simulation Platform for Recommender Systems", arXiv:1909.04847.
- Preprint.
- Code: github.com/google-research/recsim, Apache-2.0, **archived** (last push 2022-01-03).
- **Evidence level:** E3 (read in Phase 1; mapped to code in docs/RECON.md).

## Claim (own words)

- A configurable simulation platform for sequential recommender settings, with user and document models, choice models and RL agent baselines.
- Interest Evolution is one of its environments, and our only environment.
