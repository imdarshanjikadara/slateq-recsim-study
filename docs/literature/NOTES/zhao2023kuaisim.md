# zhao2023kuaisim: Zhao et al. 2023, KuaiSim (NeurIPS 2023)

- **Status:** NeurIPS 36 (2023), pp. 44880-44897. The PDF footer reads "37th Conference on Neural Information Processing Systems (NeurIPS 2023)". The track is not stated there.
- **Evidence level:** E2 (abstract and introduction).
- **Claim (own words):**
  - A data-driven user simulator built from the KuaiRand dataset.
  - Multi-behaviour, cross-session feedback.
  - Supports request-level, session-level and cross-session (retention) tasks, with benchmarks.
  - The introduction argues that existing simulators simplify user feedback and lack consistency with real data.
- **Use:** context for "why RecSim and not a newer simulator".
  - KuaiSim targets realism from logged data.
  - RecSim Interest Evolution is the environment in which SlateQ was introduced.
  - Using RecSim is what makes our RQ1 a replication.
