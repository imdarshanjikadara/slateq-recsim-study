## Problem Statement

The goal of this project is to determine whether the slate recommendation policy, implemented using a reinforcement learning approach called SlateQ, results in better engagement of the users over time compared to a conventional myopic recommendation policy focused on clicks.

**Research Question 1:** Does SlateQ's value-decomposition approach achieve higher long-term user engagement (cumulative reward) than a myopic, click-maximizing recommender in RecSim's Interest Evolution environment?

**Research Question 2:** How does the performance gap between SlateQ and the myopic baseline change as catalog size and slate size (k) increase?

**Research Question 3 (stretch goal):** How sensitive is SlateQ's advantage to violations of the user choice model it assumes - that is, does its performance hold up under a misspecified model of user behavior?

## Motivation

Current recommendation engines like YouTube, Netflix, and e-commerce use slates that comprise a collection of items displayed to users at one time; they are generally focused on clicks rather than the long-term engagement of users. Recommendation engines influence what billions of people consume, read, and purchase, but most recommendation engines are optimized for a short-term reward such as a click, forgetting that recommendations made today will affect the preferences of tomorrow and may reduce future content diversity. Reinforcement Learning provides an ideal approach for solving such a problem because it involves a series of sequential actions that come with delayed rewards instead of single predictions.

**Research gap:** An analysis of how this performance advantage scales with catalog size and slate size, which is not covered in detail in the original paper and is the project's own contribution.

**Ethical matters:** Simulation-only, with RecSim's Interest Evolution environment used for both simulated users and content - no real user data or implementation.

## Related Work

Slate recommendation can be formulated as a Markov Decision Process: state (the user's current interest), action (a slate of k items sampled from a very large collection), reward (engagement), and transition (how interest changes depending on the displayed slate). The exponential combinatorial complexity of the slate action space renders Q-learning impractical with growing size of the collection. SlateQ (Ie et al., 2019) addresses this issue by breaking down slate level Q-values into per-item Q-values under an assumed user decision-making process and was proven in production experiments on YouTube. RecSim (Ie et al., 2019) is an open-source and parameterizable simulator of the above described problem, exposing a RL API, and pre-built myopic and SlateQ agent baselines for it.

- Ie, E., Jain, V., Wang, J., Narvekar, S., Agarwal, R., Wu, R., Cheng, H.-T., Chandra, T., & Boutilier, C. (2019). Reinforcement learning for slate-based recommender systems: A tractable decomposition and practical methodology. arXiv:1905.12767. https://arxiv.org/abs/1905.12767
- Ie, E., Hsu, C., Mladenov, M., Jain, V., Narvekar, S., Wang, J., Wu, R., & Boutilier, C. (2019). RecSim: A configurable simulation platform for recommender systems. arXiv:1909.04847. https://arxiv.org/abs/1909.04847
- Google Research. RecSim: A Configurable Recommender Systems Simulation Platform (open-source repository). https://github.com/google-research/recsim

## Method(s)

The experiments conducted employ the Interest Evolution setting from RecSim, where every artificial user has an interest vector, which varies based on engagement, and every item has a feature vector, which exists within the same space, and a choice model controls the engagement of a user with a specific item.

- **MDP formulation:** State: User's interest vector at the moment. Action: A slate of k items selected from the inventory. Reward: Engagement signal generated by the user's feedback. Transition: Updating of the interest vector according to RecSim's user model.
- **Methods compared:** Random Baseline, Myopic (Immediate Engagement) Baseline, and Full SlateQ Agent from RecSim.
- **Experimental design:** Vary catalog size and slate size (k) to quantify the magnitude of the gap between SlateQ and myopic strategy; perform ≥ 3 trials for each combination and report results in terms of mean ± standard deviation; for an ambitious goal, check SlateQ's performance when the user model is wrong.
